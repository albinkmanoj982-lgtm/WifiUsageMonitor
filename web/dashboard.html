Hotspot Client Setup Guide (Phone B)

Modern phones query external DNS over port 853 (Private DNS) by default. Use either configuration below to route traffic through this filter:

Method 1: Wi-Fi Manual Proxy (Recommended)
Configure Proxy on Phone B

In Phone B's Wi-Fi network settings for this Hotspot → Advanced / Proxy:

Proxy: Manual Host: 192.168.137.1 Port: 8081
Directly intercepts HTTP/HTTPS requests. Immune to Private DNS & IPv6 bypass.
Method 2: Direct UDP 53 DNS
Disable Private DNS on Phone B

Allows Phone B to query the laptop's UDP Port 53 DNS directly:

  • Phone Settings → Network → Private DNS: OFF
  • Chrome Settings → Privacy → Use Secure DNS: OFF
  • Toggle Airplane Mode for 3 seconds to clear DNS cache
